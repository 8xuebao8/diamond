## 3.1 更新：3D 钻石表面悬停（2026-11-05）

- 鼠标停在 3D 钻石表面时，效果与停在名称上相同：对应的标注加粗高亮，相关刻面和尺寸线变绿，下方显示说明。鼠标移开后恢复原状。
- **刻面与部位**模式：刻面对应同名部位，例如停在一个星刻面上，可见的星刻面会一起高亮；腰围带对应“腰围”。
- **测量项目**模式：刻面对应最相关的测量项。台面 → 台面宽度，星刻面 → 星刻面长度，冠部主刻面 → 冠角，上腰刻面 → 冠高，腰围带 → 腰厚，亭部主刻面 → 亭角，下腰刻面 → 下腰刻面长度，底尖 → 底尖。尺寸线和角度弧线带有加宽的透明感应区，停在线上也会触发。
- 已用名称筛选时，停在被隐藏项目的刻面上会临时显示它的标注，移开后恢复筛选结果。
- 悬停只用于查看，不改变选择；点击名称或标注仍按原来的多选规则筛选。手机没有悬停，行为不变。
- 验收：用无界面 Chrome 模拟真实鼠标移动，测试了台面、亭部、腰围、冠部刻面和部位模式下的星刻面，以及筛选状态下的临时显示与移开恢复；脚本语法检查通过。

## 3.1 更新：悬停时同类一起高亮（2026-11-05）

- 测量项目模式改为与部位模式一致：悬停时，与该测量相关的同类刻面全部高亮。名称按钮、图中标注和钻石表面三处悬停用同一套规则；用名称点选筛选时也按同样规则高亮。
- 三种高亮深浅：深绿 = 鼠标下的那块，或被测量长度的那一块；绿 = 同类全部刻面；淡绿 = 高度类测量所在的区域。

| 测量项目 | 高亮范围 |
| --- | --- |
| 台面宽度 | 台面 |
| 冠角 | 8 块冠部主刻面 |
| 星刻面长度 | 8 块星刻面，量长度的那一块深绿 |
| 腰厚 / 腰围直径 | 整圈腰围 |
| 亭角 | 8 块亭部主刻面 |
| 下腰刻面长度 | 16 块下腰刻面，量长度的那一对深绿 |

## 4.0 更新：导入 GIA 报告 PDF，自动填入（2026-11-06）

“共用测量数据”卡片右上角新增绿色按钮“导入 GIA PDF / Import GIA PDF / นำเข้า PDF ของ GIA”。选择一份 GIA 钻石分级报告 PDF 后，网页会自动读取并填入输入区，并在卡片顶部显示核对面板。

**读取方式**
- **PDF 文字部分（准确）：** 报告编号、形状、尺寸（最小 – 最大 × 全深）、重量、颜色、净度、切工、抛光、对称、荧光。
- **比例图（文字识别）：** 比例图在 PDF 中是一张嵌入的图片，用 Tesseract.js 识别。可读出台宽、星刻面、冠高、冠角、全深比、亭深、亭角、下腰刻面、腰厚百分比和描述、底尖。识别出的数字按它在图中的位置和数值范围判断属于哪一项。腰厚区域字小，会单独放大再识别一次，描述词带拼写纠正（例如把 thicl 纠正为 thick）。

**填入规则**
- 直径切换为“最小 / 最大”展开模式；全深和重量按报告原值填入，小数位数保持不变（6.40、0.99）。
- 台宽和冠高需要毫米：按“比例 × 平均直径”换算（例如 56% × 6.415 mm = 3.5924 mm），冠高切换为“实测”。
- 亭角切换为“实测”，直接填报告值；亭深比直接填入。
- 腰厚切换为 % 单位，填报告的百分比；厚薄描述切换为“手动选择”，按报告描述选择最薄和最厚两项。
- 底尖按描述选择；全深比只用于核对，不填入，网页按尺寸自行计算（例如 3.94 ÷ 6.415 = 61.42%，报告印 61.5%）。
- 已有数据时先弹窗确认是否覆盖。

**核对面板**
- 逐项列出“GIA 报告值 / 填入为 / 来源”，来源分为 PDF 文字、比例图识别、未识别。旁边显示 PDF 中的比例图原图，方便对照核对。
- 未识别的项目会标注出来，请手动补填。报告形状不是 Round Brilliant 时会提示结果仅供参考。

**联网与隐私**
- pdf.js 3.11.174 和 Tesseract.js 5.1.1（含识别模型）只在点击导入时从 cdn.jsdelivr.net 加载。首次导入需要联网，约数 MB；网页的其他功能仍可离线使用。这是用户选择“全自动”方案后，对“不依赖第三方脚本”原则的有意例外。
- PDF 只在本机浏览器中读取和识别，不会上传到任何服务器。断网时会提示无法加载读取组件，可改为手动填写。

**验收（本地 HTTP 预览 + 无界面 Chrome 实际上传 PDF）**

## 4.1 更新：GIA 报告生成独立的只读卡片，不改动手动输入（2026-11-06）

**原则：手动输入和 GIA 报告分开，互不干扰**
- 上方“共用测量数据”只属于手动输入：你填了就保留，没填就是空的。导入 GIA 报告**不会改动**这里的任何数值（4.0 中“导入即填入”的做法已取消）。
- 在共用测量数据下方，新增独立区域“GIA 报告（只读）”，里面有“导入 A 报告”“导入 B 报告”两个按钮。
